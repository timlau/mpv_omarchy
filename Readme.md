## skin for mpv for Omarchy

The skin adapt colors from Omarchy theme, so then a new theme is enabled, then this skin will use the colors for the Theme.

## Contribution

The theme is based on the [ModernZ theme](https://github.com/Samillion/ModernZ) that is based on 
 - [mpv-osc-modern](https://github.com/maoiscat/mpv-osc-modern)
 - [cyl0/ModernX](https://github.com/cyl0/ModernX)
 - [dexeonify/ModernX](https://github.com/dexeonify/mpv-config/blob/main/scripts/modernx.lua)
